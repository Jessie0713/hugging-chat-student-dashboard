# 練習建議推薦機制（Fixed / Rolling）

> 儀表板「練習建議」頁：觀察 → 策劃 → 行動。學生勾選弱點（focus）後，最多推薦 **2** 間聊天室。

---

## 課程目標（前提：有效對話）

兩邊都必須在**有效對話完成**的前提下才算進進度：

| 模式 | 一間聊天室／主題算進進度的條件 |
| --- | --- |
| **Fixed** | 選「進階」＋評估 ≥ 進階＋**有效對話完成**；每個 assistant 最多 1；目標 **6** |
| **Rolling** | 評估 ≥ 進階＋**有效對話完成**；不同 assistant；目標 **6** |

有效對話：`badge.stats.perAssistant[].effectiveRoundComplete`（語音、全英文、內容達標等合格輪）。

評估大階：PreA1→入門；A1/A2→基礎；B1/B2→進階；C1/C2→高階。

---

## 推薦三步

```
① focus 共用計分  →  ② 模式個別（rank）  →  ③ 排序取前 2（同主題只留 1）
```

| 步驟 | Fixed | Rolling |
| --- | --- | --- |
| **① focus** | 各 focus 相關分加總 | 同左 |
| **② 模式** | rank 分桶 | rank + 一次 bonus |
| **③ 排序** | rank → focus 分 | 同左 |

---

## Fixed rank

| rank | 條件 |
| ---: | --- |
| **0（最前）** | **選進階**＋評估 ≥ 進階，但有效對話未完成 |
| 1 | 選進階，評估 ＜ 進階 |
| 2 | 選等級，評估 ＜ 選定 |
| 3 | 其他 |
| **4（最後）** | 選進階＋評估 ≥ 進階＋有效對話已完成（已算進進度） |

---

## Rolling rank

| rank | 條件 |
| ---: | --- |
| **0（最前）** | 評估 ≥ 進階，有效對話未完成 |
| 1 | 尚未到達進階 |
| **3（最後）** | 評估 ≥ 進階且有效對話已完成 |

Bonus：入門／基礎 +6；`confidence` ＜ 0.85 +0.5。

---

## Focus 計分

| 條件 | 分數 |
| --- | ---: |
| advice.focus 命中（含近義歸類） | +5 |
| nextTask 關鍵字 | +3 |
| 情境描述 | +2 |
| 名稱 | +1 |

---

## 一句話

- **Fixed**：選進階＋程度到了、只差有效對話 → 最優先
- **Rolling**：評估≥進階、只差有效對話 → 最優先
- 兩邊都完成 → 才算達標、推薦排最後
